# 진성 활동 고객 피처·모델 재평가 (2026-08-01)

## 목적과 자료

기존 9,879명 전체 활동 사용자에서 계산한 SHAP 중요도를 진성 고객 모델의 근거처럼 사용하지 않기 위해, **진성 활동 고객 2,381명**만으로 피처 선정과 CatBoost 불균형 처리 실험을 다시 수행했다. 이 중 기준일 이후 30일 무경기는 363명(15.25%)이다. 라벨은 계정 탈퇴나 로그인 중단이 아닌 경기 기록 기준이다.

입력은 기준일 이전의 사용자별 집계 33개다. 식별자·배치 ID·세그먼트·미래 `churn`은 제외했다. 7개 파생변수는 기존 활동량·경기 간격·모드 비율에서 기준일 이전 값끼리 계산했다. 추가 피처는 `recent_activity_ratio`, `last_week_share`, `games_per_active_day`, `last_vs_typical_gap`, `gap_spread`, `ranked_share`, `mode_concentration`이다. 시드 티어는 일부 사용자만 매칭되고 수집 시점이 불명확해 입력에서 제외했다.

## 실험 방법

- 피처 집합: 기존 33개 / 파생 포함 40개 / 학습 fold에서 CatBoost SHAP으로 선정한 상위 15개.
- 불균형 처리: 무처리 / 양성 클래스 가중치 2 / fold 내 클래스 수로 계산한 균형 가중치 / ROS / SMOTE. 총 15개 조합.
- 모든 후보는 같은 5-fold 분할에서 비교했다. 결측치 중앙값 대체, SHAP 순위, ROS·SMOTE는 각 학습 fold에만 맞췄다. SMOTE는 학습 데이터에서만 표준화 후 합성하고 원래 단위로 되돌렸다.
- 별도로 5개 외부 fold마다 내부 3-fold에서 후보를 고르는 **중첩 CV**를 수행해, 후보 선택 절차의 낙관적 편향을 확인했다.
- 선택 기준은 5-fold OOF PR-AUC(AP) 최대값이다. 동률일 때 F1@20%를 참고한다. 이는 탐색용 선택 기준이며 사후 선택한 최고 점수를 독립 검증 성능으로 주장하지 않는다.

## 결과

| 평가 | PR-AUC | ROC-AUC | Recall@20% | Precision@20% | F1@20% | 상위 20% 실제 무경기 |
|---|---:|---:|---:|---:|---:|---:|
| 후보 선택 **절차** · 중첩 CV | 0.382 | 0.778 | 51.2% | 39.0% | 0.443 | 186/477명 |
| 선택 후보 · 사후 탐색 OOF | 0.410 | 0.783 | 52.3% | 39.8% | 0.452 | 190/477명 |
| 같은 이번 분할의 고정 33개·무처리 | 0.391 | 0.782 | 50.4% | 38.4% | 0.436 | 183/477명 |
| 기존 무가중치 모델 · 이전 실험 | 0.397 | 0.783 | 52.1% | 약 39.6% | 0.450 | 189/477명 |

선택 후보는 **기존 집계 33개 + CatBoost 클래스 균형 가중치**다. 전체 데이터 363:2,018의 양성 가중치 비율은 약 5.56이며 실제 fold에서는 해당 학습 fold의 비율로 계산한다. 후보별 전체 수치는 [`candidate_cv.csv`](candidate_cv.csv)에 있다. 이번 동일 분할의 기존 33개 무처리 후보는 PR-AUC 0.391이었다. 파생 포함 40개 무처리는 0.406, SHAP 상위 15개 + 균형 가중치는 0.408, ROS·SMOTE 후보는 모두 선택 후보보다 낮았다.

**성능 개선이 확인됐다고 결론내릴 수 없다.** 최고 후보의 0.410은 비교·선택에 같은 표본을 쓴 사후 점수다. 같은 이번 분할에서 고정 33개 무처리의 0.391이 중첩 선택 절차의 0.382보다 높다. 중첩 CV의 0.382와 이전 기준 0.397은 fold 구성과 전처리가 달라 숫자만으로 직접 비교하지 않는다. 중첩 CV 외부 fold의 선택 조합도 일정하지 않았다([`nested_fold_choices.csv`](nested_fold_choices.csv)). 별도 기준일의 시간 외 검증이 필요하다.

| 중첩 CV 하위군 | 사용자 / 실제 무경기 | PR-AUC | Recall@20% |
|---|---:|---:|---:|
| 솔로랭크 중심 | 1,026 / 139 | 0.353 | 46.8% |
| 그 외 플레이 유형 | 1,355 / 224 | 0.406 | 54.5% |

하위군의 이탈 비율과 표본 수가 다르므로 PR-AUC 숫자만으로 사용자 유형의 예측 난이도나 개입 가치를 단정하지 않는다. 하위군 수치는 전체 모델 OOF를 분리 평가한 결과이며 유형별 별도 모델을 학습한 성능이 아니다.

## 진성 고객 기준 SHAP

선택된 33개 피처로 **진성 고객 전체를 재학습한 최종 후보 모델**의 평균 절댓값 SHAP 상위 변수:

| 변수 | 평균 절댓값 SHAP |
|---|---:|
| 마지막 경기 경과일 | 0.593 |
| 최근 7일 경기 수 | 0.347 |
| 최근 30일 활동일 | 0.301 |
| 최근 20경기 모드 전환율 | 0.235 |
| 최근 승률 변화 | 0.148 |
| 마지막 경기 간격 | 0.130 |

전체 33개 값은 [`selected_model_shap_importance.csv`](selected_model_shap_importance.csv)에 있다. 이 값은 **선택된 최종 모델** 기준이다. SHAP 축소안의 피처 선정 순위는 각 학습 fold에서만 계산했으며 [`core_shap_importance.csv`](core_shap_importance.csv)에 전체 2,381명 무가중치 탐색 모델의 참고 순위와 fold별 상위 15개 포함 횟수를 별도로 기록했다. 둘을 혼동하지 않는다. SHAP은 모델이 이용한 정보의 크기이지 이탈 원인·보상 효과가 아니다.

## 대시보드 반영과 한계

[`oof_predictions.csv`](oof_predictions.csv)의 `selected_candidate_oof_score`를 위험 사용자 정렬에 쓴다. 전체 사용자를 재학습한 [`selected_model.cbm`](selected_model.cbm)은 **향후 입력에 점수를 낼 후보 모델**이며, 화면에 보이는 2,381명 점수는 해당 모델의 학습 내 예측이 아니라 5-fold OOF다. 위험 등급은 점수 70점 같은 임의 절대값 대신 **상위 10% / 다음 10% / 나머지 80%** 순위 구간이다. 가중치로 점수 눈금이 변하기 때문에 이 점수를 보정된 개인별 확률로 부르지 않는다.

현재는 기준일이 하나뿐이고 Riot API 수집 범위가 제한적이다. 이 실험은 시간 외 검증, 확률 보정, 정책 효과의 A/B 테스트를 마치지 않았다. 합성 생존분석은 별도 데모이며 이번 CatBoost 실험의 성능 근거가 아니다.
